One funny line a hopeless tech support agent gives a desperate customer, for the [Have You Tried Turning It Off? bounty](https://make.fun/competitions/u-motasimfuad-have-you-tried-turning-it-off-154a938b) on make.fun.

> Have you tried turning it off and on again? I ask because I turned my own brain off in 2019 and the calls never stopped.

`main.py` (Python 3.13, standard library only) validates the line against the gate — 1 to 199 characters, single line, UTF-8 — and writes it to `/output/entry.txt`. Run `python3 main.py --check` for a dry-run validation.
